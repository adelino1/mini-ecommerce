# Mini Ecommerce

Sistema de ecommerce desenvolvido com Angular + PHP Puro + MySQL.

## Tecnologias
- Frontend: Angular 17+
- Backend: PHP 8+ puro
- Base de Dados: MySQL

## Setup Local
1. Clonar repositório em `C:\xampp\htdocs\mini-ecommerce`
2. Iniciar Apache e MySQL no XAMPP
3. Importar `database/schema.sql` no phpMyAdmin
4. `cd frontend && npm install && ng serve`
5. Aceder a `http://localhost:4200`
